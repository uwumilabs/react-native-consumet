# Upgrading from 1.6.0

Every breaking or behaviour change since 1.6.0 that an app may need to handle, with a link to the details. Items marked **Breaking** need a code or data change in most apps. The others change what an app sees but need no change unless it relied on the old behaviour.

| **Breaking.** `new ProviderManager(registry)` and `new ExtractorManager(registry)` throw a `RegistryError` for a missing or invalid registry, or one with a newer `schemaVersion`. To share the extractor cache with your own code, pass `{ extractorManager }`.                                                                                                | [ExtractorManager](../extension-integration.md#extractormanager)                                         |
| Factories receive the registry entry's `baseUrl`, and loaded providers are cached per id, `sha256` and `baseUrl`. `getAnimeProvider` / `getMovieProvider` / `loadExtension` accept `{ baseUrl }`.                                                                                                                                                                               | Custom registries: make `baseUrl` the provider's site.                                                                                                                             | [ProviderManager](../extension-integration.md#providermanager)                                           |

| Code downloads abort after 30 s instead of hanging.                                                                                                                                                                                                                                                                                                                             | None.                                                                                                                                                                              | [Security Model](../security.md#4-https-and-bounded-downloads)                                           |

Use `getProvider` for other categories.                                                                                                                                      | [ProviderManager](../extension-integration.md#providermanager)                                           |

Call `invalidate` to force a reload.                                                                               | [ProviderManager](../extension-integration.md#providermanager)                                           |
| **Breaking.** `loadExtractor` always returns an extractor instance. ## URLs (`PolyURL`)

| Change                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             | What to do                                                                                                                                                       | Details                                                                           |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| **Breaking.** `PolyURL` and `PolyURLSearchParams` follow the WHATWG URL Standard. Invalid input or an invalid base throws a `TypeError` instead of giving a broken URL. `'/foo'` and `'?q=1'` resolve against a base correctly. `pathname` keeps its percent-encoding (`%2F` stays `%2F`). Hosts are lower-cased and punycoded, and default ports are dropped. Query strings serialize a space as `+` and `~` as `%7E`, keep repeated names in order, and `has` / `delete` take an optional value. | When parsing scraped URLs, pass a base (`new PolyURL(href, pageUrl)`) or catch the `TypeError`. Decode `pathname` yourself where you relied on it being decoded. | [Using `ProviderContext`](../guides/adding-new-provider.md#using-providercontext) |
